## 4. 데이터 수집 단계별 특징 및 유의점
1. **1단계 (공식 API)**: 가장 신뢰도가 높으며 접수번호 기반 공시일(disclosed)과 출처 URL 자동 생성. 단, 기업별 고유번호 및 인증키 관리 필수.
2. **2단계 (파이썬 라이브러리)**: API 없이 바로 DataFrame으로 수집되어 가장 편리하나 네이버 금융 등 중간 매개체를 거치므로 신뢰도는 '중'으로 부여.
3. **3단계 (파일 다운로드)**: 원본 파일 다운로드 방식. 칼럼 헤더나 인덱스 파싱 규칙(날짜 컬럼 지정) 확인 필요.
4. **4단계 (크롤링)**: 웹페이지 변경에 취약하고 robots.txt 준수 필수. 수집 데이터는 전부 '확인 필요'로 넘어가 수동 검증이 강제됨.
5. **5단계 (수동 입력)**: 증권사 리포트 추정치 등 비정형 데이터는 `출처카드` 시트 및 `files/` 폴더 내 정형 CSV(`항목,값,단위,기준일`)로 규격화하여 엔진에 연결.
